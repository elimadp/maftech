# מפתח – האפליקציה המותקנת

מה יש כאן:
- `index.html` – האפליקציה עצמה (אותה אפליקציה כמו בקישור של Claude, עם התקנה למסך הבית ועבודה גם בלי אינטרנט).
- `manifest.webmanifest`, `sw.js`, `icons/` – מה שהופך אותה לאפליקציה שאפשר להתקין.
- `netlify.toml`, `package.json`, `netlify/functions/` – הגדרות ל-Netlify, והשרת הקטן של השיתוף החי.
- `pipeline/` – סקריפט העדכון היומי, הבדיקות והנתונים שהוא צריך.
- `.github/workflows/update.yml` – העדכון היומי האוטומטי ב-GitHub (חינם, בלי Claude).

## הקמה, פעם אחת

### 1. GitHub
1. ב-github.com: New repository, שם `maftech`, אפשר Private.
2. Add file → Upload files → לגרור את **כל התוכן** של התיקייה (אחרי חילוץ ה-ZIP) → Commit.
3. לבדוק שיש בריפו תיקייה `.github/workflows`. אם אין (חלק מהמחשבים לא מעלים תיקיות שמתחילות בנקודה):
   Add file → Create new file → בשם הקובץ לכתוב `.github/workflows/update.yml` → להדביק את התוכן של הקובץ מה-ZIP → Commit.

### 2. Netlify
1. Add new site → Import an existing project → GitHub → לבחור `maftech`.
2. Build command: ריק. Publish directory: `.` → Deploy.
3. אפשר לשנות את שם האתר ב-Site configuration → Change site name.

### 3. התקנה בטלפון
- אנדרואיד (Chrome): לפתוח את הכתובת → תפריט ⋮ → "התקנת אפליקציה" / "הוספה למסך הבית".
- אייפון (Safari): לפתוח את הכתובת → כפתור השיתוף → "הוסף למסך הבית".

### 4. העברת הנתונים שלך
1. בגרסה של Claude: גלגל השיניים → שמירת גיבוי.
2. באפליקציה המותקנת, במסך הפתיחה: "שחזור מגיבוי" → לבחור את הקובץ.

### 5. העדכון היומי
- רץ לבד כל בוקר (Actions → daily-data-update). כדי לבדוק מיד: Run workflow.
- אם הוא נכשל ב-Publish עם שגיאת הרשאה: Settings → Actions → General → Workflow permissions → Read and write.
- אם בדיקה נכשלת, לא נשמר כלום והגרסה הקודמת נשארת באוויר.

### 6. שיתוף חי עם בן/בת הזוג
- גלגל השיניים → "יצירת קוד שיתוף". בטלפון השני: גלגל השיניים → "יש לי קוד" → להקליד את הקוד.
- מאותו רגע שני הטלפונים רואים ומעדכנים את אותה רכישה. שינויים מגיעים לטלפון השני תוך כמה שניות, וגם כששניכם משנים באותו זמן שום דבר לא נמחק.
- הנתונים המשותפים נשמרים ב-Netlify שלך (Netlify Blobs). מי שיודע את הקוד יכול לראות ולשנות, אז שתפו אותו רק ביניכם.

## מה מתעדכן לבד כל בוקר
- עסקאות הנדל"ן, מחירי השכונות והגרלות מחיר למשתכן.
- ריבית בנק ישראל, הפריים ומועד ההחלטה הבאה (מהממשק הרשמי של בנק ישראל).
- מדד המחירים לצרכן, מדד מחירי הדירות ומדד תשומות הבנייה (מהממשק הרשמי של הלמ"ס).
- ממוצעי ריבית המשכנתאות עדיין לא מתעדכנים לבד.

## מה שונה מהגרסה של Claude
- בלי שיתוף, הנתונים שלך נשמרים בטלפון. להעברה לטלפון אחר: גיבוי ושחזור, או שיתוף.
- צירוף קבצים למסמכים זמין כרגע רק בגרסה של Claude.
